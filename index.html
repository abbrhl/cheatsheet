🚨 W2: Incident Response SRV002

Onderzoek naar het MySQL datalek en server hardening.

  • 4 Vragen: Hoe, Wanneer, Welke info, Hoeveel buit?
  • MySQL Hardening: Root WW wijzigen, anoniem account weg, remote root login uit.
  • RAT Removal: Check TeamViewer/AnyDesk/ngrok.
  • AVG: Meld datalek binnen 72u bij AP.
